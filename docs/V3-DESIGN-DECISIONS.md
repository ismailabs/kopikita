# KopiKita MY V3 design decisions

18 October 2026. Primary specification: the approved V3 handoff and selected Concept B, Kopi Culture / Graphic Modernism. Reference materials are locally excluded and never deployed.

The memorable element is the pine hero: three lines of locally hosted DM Serif Display, an iced-coffee image in an arch and an offset tangerine arch. The surrounding interface stays quiet. The page continues through ivory favourites, oat story, ivory menu, an oat photographic mosaic and a pine studio invitation. DM Sans carries body/UI text; prices use tabular numbers. Exact tokens are pine #103D34, pine ink #0A2B25, paper #F7F2E9, oat #E9DDCC, tangerine #F27C43, cocoa #30251E and secondary ink #665C52. Small text on orange uses dark pine. The stamp has opaque pine after an actual axe finding on ivory-over-orange labels.

One semantic scrolling page and the established vanilla stack are retained. No new runtime library or network dependency is justified. Original 30 names, descriptions, categories, display prices, row IDs and four favourite targets remain canonical. No ordering, reservations, operational history, venue information or testimonials have been added. Top/menu/footer disclosures, CreativeWork, canonical URL, noindex and both exact studio destinations remain.

Desktop uses a 55/45 opening and four alternating product frames. Tablet retains the split hero/story, with two-column favourites. Mobile stacks copy and image, keeps a two-column favourites layout when space permits, and wraps the menu controls. Favourites adapt to a single column with enlarged text; gutters do not grow with text size. At 375px the two hero actions share a row; 320px can wrap as needed. Menu descriptions are 15px rather than the reference prototype's smaller text. Desktop menu categories sit in two columns; filtered categories occupy the reading width. Original category copy and item icons are preserved rather than replaced by invented reference content.

All photographs are existing local synthetic production images, inspected at rendered size. The existing original botanical header symbol is retained for identity continuity; the decorative hero line drawing is original inline SVG. No preview photo crops or boards become production assets. Story imagery is a tighter crop of an existing landscape source and is softer than the product photography; no documentary venue claim is made. Retained source assets and the truthful earlier social cover remain available; none are deleted.

Native motion clarifies filtering, small image responses and the phrase strip. Entrances and filtering translate fully opaque content. The ticker has pause/resume, viewport/document pause and static no-JS/reduced-motion behavior. No scroll trapping or GSAP is needed. Navigation remains usable without the deferred script and all 30 rows remain in source with no JavaScript. The early navigation controller is preserved to avoid loading shift.

Actual baseline/local/public screenshots and gate results are indexed in V3-RELEASE-REPORT.md. The first visual pass prompted compact mobile action spacing and adaptive text reflow; paused motion contrast and strict full-page axe checks remain release gates.
